# RCS Registrations

Next.js and TypeScript frontend that displays RCS capture-the-flag registration data in a table. The main page renders `app/Table.tsx` and uses Tailwind CSS for styling.

## Getting started

Set `NEXT_PUBLIC_DATA_URL` to an accessible endpoint returning registration records with `name` and `uni_id` fields. Then run `npm ci`, then `npm run dev`, and open `http://localhost:3000/`. Build with `npm run build` and serve a production build with `npm start`.
